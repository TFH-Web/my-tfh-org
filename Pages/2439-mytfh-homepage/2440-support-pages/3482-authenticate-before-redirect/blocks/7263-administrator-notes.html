Instructions on how to use this page

This page is used to require a user to authenticate themselves before being redirected to a public my.tfh.org page.


Examples

https://my.tfh.org/authenticate?redir=2847
https://my.tfh.org/authenticate?redir=group-resources
https://my.tfh.org/authenticate?redir=group-resources%2Fgroup&groupId=130211
