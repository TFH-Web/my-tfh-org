{%- comment -%} Discover — week detail (page 4050, route class/discover/{ClassWeek}) ------------------------------------------------------------------- One week of the class: its date, its agenda, and any resources attached to an agenda item. ROUTE PARAMETER {ClassWeek} is a slug of the fixed form "week-1", "week-2". It is a controlled vocabulary, not derived from a name, which is what keeps it clear of the slug-normalisation trap documented in CLAUDE.md. It is still untrusted URL input, so it is sanitised to [a-z0-9-] before use and then range-checked against the weeks this person actually has. WHAT IS DATA-DRIVEN The week list and its dates, from the person's Discover placement group -> EventItem -> occurrences. Same query as page 4049. WHAT IS HARD-CODED (beta) Every agenda, in the AGENDA COPY section. Written as literal markup per week rather than encoded into a Lava array, so a non-developer can edit a line without decoding a delimiter scheme. Week titles and summaries must stay in step with 8826-in-class-experience-html.html on page 4049.
